## 4. PDF-Generation Architecture & Dependency Evaluation

### Evaluation of Options:
- **External Client-Side Libraries (`jsPDF` / `pdfmake`)**: Rejected. Standard client-side PDF libraries lack complex text shaping (HarfBuzz) out-of-the-box and either fail or garble Malayalam conjuncts (`ന്റ`, `ക്ക`, `ച്ച`, `ർ`, etc.) as square boxes (`□□□`) or disconnected glyphs. Adding custom fonts and shaping would inject multi-megabyte external bundles, violating the single-file HTML constraint.
- **Browser-Native Print-to-PDF (`#print-area` + `@page A4 landscape` + `window.print()` / `Page.printToPDF`)**: Selected.
  - Preserves 100% single-file architecture with zero external dependencies.
  - Leverages the browser engine's DirectWrite/HarfBuzz font shaper for Malayalam Unicode.
  - Renders genuine A4 landscape layout (`MediaBox [0 0 841.92 594.96]`).
  - Implements standard accounting table pagination with repeating `thead` and preserved `tfoot`.
  - Sets browser document title dynamically to `Ledger_Report_[DateRange].pdf` so the native "Save as PDF" dialog suggests the exact filename.
